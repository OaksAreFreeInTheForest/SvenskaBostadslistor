# Bidra till listorna

Alla är välkomna att bidra till existerande bostadslistor, eller skapa nya bostadslistor.

Bostadslistorna skrivs i markdown (.md filer), där filnamnet motsvarar staden eller området som listan har bostadsköer över.

Listorna börjar med områdesbenämmning some första rubrik (#). 

Sedan sorteras listan med andra-rubrik (##), i ordning av:
- Kommunala
- Privata
- Second Hand
- Studentlägenheter

Sist i listan kan relevanta närliggande bostadsköer listas. Välj en valfri lämplig rubrik, såsom  Bostadsköer utanför «Område», eller lägg till extra beskrivning om listan täcker en specifik typ av bostadsköer, exempelvis "Kommunala bostadsköer utanför Göteborg".

Bostadsköer inom vadera rubrik listad en per rad enligt:
`- Namn_på_bostadskön: https://länk_till_bostadskö.se`

Detta gör att listan kan kopieras och delas överallt och ändå behålla läsligheten.
