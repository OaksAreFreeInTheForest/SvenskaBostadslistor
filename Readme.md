# Svenska Bostadsköer

Detta repo innehåller listor över bostadsköer för olika regioner, baserat på område / stad, som sorters efter kommunala och privata bostadsköer. Listorna anordnas av människor som vill hjälpa till att ordna upp all bostadsköer som finns för olika områden.

Listorna innehåller bostadsköer primärt för dess område, men kan innehålla relevanta bostadsköer för närliggande områden. Köerna i listorna är inte fullständiga listor över alla köer som finns.
